# Spring Boot Microservices Practice

This repository contains two Spring Boot practice projects exploring the development of REST-based microservices for user and order-related operations.

## Projects

| No. | Project Name                   | Description                                                         |
| --- | ------------------------------ | ------------------------------------------------------------------- |
| 1   | `SpringBootMicroservicesOrder` | Demonstrates an Order service using Spring Boot and REST endpoints. |
| 2   | `SpringBootMicroservicesUser`  | Demonstrates a User service using Spring Boot and REST endpoints.   |

## Technologies Used

* Java
* Spring Boot
* Spring Web
* REST APIs
* Maven

## Concepts Covered

* Microservices architecture fundamentals
* Building RESTful web services
* Controller-based request handling
* Separating application responsibilities into services
* Running independent Spring Boot applications

## Prerequisites

* JDK compatible with each project's Spring Boot version
* Maven
* An IDE such as Spring Tool Suite (STS) or IntelliJ IDEA
* Basic knowledge of Java, Spring Boot, and REST APIs

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/afrin2326/Spring-Boot-Microservices.git
   ```

2. Open either project folder separately in your IDE.

3. Check the project's `pom.xml` and `application.properties`.

4. Configure any required application settings.

5. Run the main Spring Boot application class.

**Note:** These are separate practice projects. Check the source code and endpoint mappings to understand the actual functionality and whether the services require additional configuration to communicate with each other.

## Repository Structure

```text
Spring-Boot-Microservices/
├── SpringBootMicroservicesOrder/
└── SpringBootMicroservicesUser/
```

Each directory contains its own Maven configuration and source code.
